# Nthuseng Learning Room

### Building confident learners, one step at a time.

## Project Overview

Nthuseng Learning Room is an AI-powered educational productivity application designed to support learning-support practitioners in providing personalised learning support to learners.

The application uses Artificial Intelligence to assist with common educational tasks such as planning personalised learning sessions, summarising learner session notes, and creating professional communication for parents.

The project was developed to demonstrate the practical use of AI to solve a real-world educational problem while maintaining responsible AI practices and human oversight.

The main workflow of the application is:

**Learner → Session Notes → AI Summary → Learning Plan → Progress → Parent Communication**

Nthuseng Learning Room is designed as one integrated platform rather than a collection of separate applications.

---

## Features

### 1. AI Learning Session Planner

The AI Learning Session Planner helps practitioners create personalised daily or weekly learning plans based on the learner's grade, skill area, current ability, learning goals, and priority areas.

It can generate:

- Learning objectives
- Priority skills
- Learning activities
- Suggested materials
- Session duration
- Differentiation strategies
- Progress indicators

---

### 2. AI Session Notes Summarizer

The AI Session Notes Summarizer converts detailed learner session observations into a structured summary.

It can identify:

- Session summary
- Strengths observed
- Areas for growth
- Progress observed
- Challenges
- Recommended next steps
- Suggested focus for the next session

This helps reduce the time required to organise and document learner progress.

---

### 3. AI Parent Communication Generator

The AI Parent Communication Generator helps practitioners create professional and supportive messages or emails for parents.

Users can select different communication types and tones, including:

- Professional
- Warm
- Friendly
- Encouraging
- Concise

The generated communication can be edited before it is shared with a parent.

---

### 4. AI Learning Assistant

The AI Learning Assistant provides educational support and suggestions for practitioners.

It can assist with:

- Literacy activities
- Mathematics activities
- Differentiation strategies
- Learning games
- Session planning
- Teaching strategies
- Low-cost learning materials

---

### 5. Learner Profiles

The application allows practitioners to maintain learner profiles containing information such as:

- Grade
- Learning focus
- Strengths
- Areas for growth
- Learning goals
- Progress information
- Session history

Fictional learner data is used for demonstration purposes.

---

### 6. Progress Tracking

Practitioners can record learner progress, including:

- Skills practised
- Activities completed
- Learner responses
- Successes
- Challenges
- Level of support required
- Next steps

Progress can be viewed using visual indicators and summaries.

---

### 7. Responsive Dashboard

The application includes a modern dashboard with:

- Sidebar navigation
- Learner management
- AI tools
- Progress information
- Quick actions
- Responsive mobile and desktop layouts

## Prompt Engineering

Structured prompts were used to improve the quality and reliability of AI-generated responses.

The prompts use elements such as:

- Role
- Context
- User input
- Task
- Constraints
- Output format
- Responsible AI instructions

The AI is instructed to use only information provided by the practitioner, avoid unsupported claims, use strengths-based language, and avoid diagnosing or labelling learners.

---

## Responsible AI

Nthuseng Learning Room is designed with responsible AI use in mind.

AI-generated content is intended to support educational planning, documentation, and communication. It does not replace professional educational judgement, formal assessment, diagnosis, or advice from appropriately qualified professionals.

The practitioner remains responsible for reviewing and approving AI-generated content before using it with a learner or sharing it with a parent.

The application also encourages users to avoid entering unnecessary sensitive or personally identifiable learner information.

Fictional learner information is used for demonstration purposes.
