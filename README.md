# Nthuseng Learning Room AI Assistant

Building confident learners, one step at a time.

---

## Project Overview

Nthuseng Learning Room AI Assistant is an AI-powered platform designed to assist educational practitioners and learning-support professionals with learner profiling, learning planning, activity generation, progress reporting, and parent communication.

The platform helps reduce administrative workload while supporting consistent educational planning and communication.

---

## Problem Statement

Educational practitioners spend significant time:

- Conducting learner assessments
- Developing learning plans
- Writing progress reports
- Creating activities
- Communicating with parents

These tasks are important but time-consuming.

---

## Solution

Nthuseng Learning Room AI Assistant provides an integrated AI-powered workflow that helps practitioners:

- Analyse learner information
- Create learning plans
- Generate learning activities
- Produce progress reports
- Draft parent communications

while ensuring that professional judgement remains central to all decisions.

---

## Features

### 1. AI Learner Profile Assistant

Generate:

- Learner strengths
- Areas requiring support
- Learning priorities
- Recommendations

### 2. AI Learning Plan Generator

Generate:

- Learning goals
- Suggested activities
- Resources
- Progress indicators

### 3. AI Activity Generator

Generate:

- Literacy activities
- Mathematics activities
- Practice exercises

### 4. AI Progress Report Generator

Generate:

- Parent-friendly progress reports
- Progress summaries
- Recommendations

### 5. AI Parent Communication Assistant

Generate:

- Parent updates
- Welcome emails
- Follow-up messages
- Session reminders
